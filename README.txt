Leafnote

Serve dist/ with a static web server, or use the private hosted app. PDF workers and document storage need HTTP(S); opening index.html as a local file is not supported for PDFs.

Includes notebooks, all-note search, handwriting search, favorites, free-position plain text, pen and highlighter strokes, stroke erasing, per-page undo/redo, optional paper styles, brainstorm boards, and full JSON backups. New notes start as blank sheets without preset headings or sections; note names and notebook controls sit outside the paper.

Search all notes: use the search field above the note list or Ctrl/Cmd+K. A query searches every notebook, regardless of the selected notebook. Search matches names, typed notes, idea cards, PDF text, typed PDF annotations, and indexed handwriting. Results identify matching PDF pages and open that page. Typed/recognized ink results show a temporary highlight, which is excluded from exports.

Handwriting search: searching All content or Handwriting automatically indexes missing or outdated recognition after a short pause. You can turn this off with Recognize handwriting when searching, or use Index all notes to retry manually. Use Language models to review and install English (about 65 MB) or experimental Marathi / Devanagari (about 7.6 MB). Recognition runs in a browser worker on this device. Existing English models cached by earlier versions can be adopted without another download. Notes and handwriting images are not uploaded. A WebAssembly runtime is bundled with the app. Recognition can make mistakes, especially for sketches, crowded layouts, non-English text, and unusual handwriting. The Review handwriting button beside search shows the current note/page transcript and lets you correct it without changing the ink. This is useful for proper names. Click between characters and use Backspace/Delete or select text and replace it. Save corrections waits for storage success, keeps the editor open, and marks the edited transcript as the search text. Background recognition cannot overwrite a saved correction for unchanged ink. Unsaved edits are retained when you close/reopen review or switch notes within the open app; use Save corrections to preserve them through a reload. Discard edits returns to the saved transcript. Try recognition again produces a review draft and preserves the saved transcript until you explicitly save. Detached dots and short marks are grouped with nearby handwriting lines before recognition. Search uses the best reading plus up to two alternative readings; user-reviewed corrections are preserved on model/index upgrades. New or erased ink is marked as needing reindexing; its old recognition is excluded from results until reindexed. Search shows source-filter restrictions, hidden matches in other content types, index coverage, unreadable pages, and recognition errors explicitly. Existing PDFs acquire a text index when Index all notes runs; new PDF imports extract their text immediately. Image-only PDF backgrounds are not OCR-indexed, but handwriting added to them is supported.

Brainstorm boards: choose Brainstorm board. Boards begin at 3200 x 2400 logical units and expand in both directions toward the right/bottom using More space or by drawing near an edge. This is an expansive canvas with a 100,000-unit limit per dimension, rather than mathematically infinite storage. Pan with the Pan tool, Space+drag, trackpad scrolling, or touch. Use zoom buttons, Ctrl/Cmd+wheel, and Fit board. Add idea cards, choose Select to click/select or drag cards, and double-click a card (or choose Type) to edit, and choose Connect then two cards to link them. Repeating a connection removes it. Delete card removes the selected card and its connectors; undo/redo includes card creation, editing, movement, connections, and expansion. Freehand ink and plain text work alongside cards. Boards, connectors, and search indexes are included in full backups.

Choose Type and click anywhere to write directly on the sheet or PDF. Spaces and line breaks are preserved, and Tab inserts four spaces. Click existing text to edit it. Escape or Ctrl/Cmd+Enter finishes the current text entry. Choose text size and line spacing before starting a new text entry. Plain notes grow vertically as you type; imported PDF page sizes remain fixed. Existing formatted notes are converted to plain text without discarding their words. Export keeps both free-position text and ink in a printable document.

Import PDFs up to 25 MB / 1,000 pages. Navigate pages, zoom, write, highlight, and use Type to write text directly on the page without a popup form. Export PDF keeps original pages and flattens annotations into transparent image overlays. Original document text is retained. Password-protected PDFs must be unlocked before import. Changes to signed PDFs invalidate signatures. The eraser removes ink; edit text with Type to change or delete it.

Stylus: pressure-sensitive pen outlines, coalesced pointer samples, smoothed edges, hardware eraser, and captured pointer isolation. Default input accepts pen/mouse and lets fingers scroll. Choose Stylus only to reject mouse drawing or enable finger drawing explicitly. Pressure and hardware eraser depend on browser/device support. Choose Pen/Highlight before writing. Keyboard: P pen, E eraser, Ctrl/Cmd+Z undo and Ctrl/Cmd+Shift+Z redo annotations outside text fields.

Notes and original PDFs save in IndexedDB on the current browser and origin. Existing v1 localStorage notes migrate automatically and remain as a recovery copy. Full backups include original PDFs and per-page editable annotations; legacy text-only backups can still be imported. Clearing site data removes local notes and PDFs. Export backups regularly. No cloud sync, audio recording, collaboration, or handwriting-to-editable-text conversion is implemented.

The hosted app and local preview use separate browser storage. Use Export backup / Import backup to move notes between them. Cloud sync is deferred. Audio/transcription, images, handwriting-to-text/math conversion, and AI study tools are future reference features and are not implemented.

PDF renderer: Mozilla PDF.js 6.5.438 (Apache 2.0). PDF export: PDF-Lib 1.17.1 (MIT). Handwriting: Transformers.js 3.8.1 (Apache 2.0), ONNX Runtime Web (MIT), and Xenova/trocr-small-handwritten (MIT), pinned to revision 02bea33ca09a70e2e2d91140a7e6e1a729606a5b. Model card: https://huggingface.co/Xenova/trocr-small-handwritten . Runtime libraries and licenses are bundled in dist/vendor. English model files download from Hugging Face; Marathi model files are served with this app. Documents are not uploaded to these projects or CDNs.

Language models: each curated model card shows its language, download size, licence, source, validation, and limitations before installation. Install uses a dedicated IndexedDB database, verifies available SHA-256 checksums, supports cancellation, and resumes verified partial downloads. Remove clears that model from Leafnote model storage and the legacy Transformers cache, stops active recognition, and preserves every note, ink stroke, and saved search transcript. Removing a model does not silently reinstall it. Installed files are device/browser-specific, separate from note backups.

For Marathi: Language models > Review model details > Install > Use for this page. In Review handwriting choose Try recognition again, edit the draft if necessary, then Save corrections. The language is saved per note or PDF page. Saved corrections remain searchable when a model is removed or the page language changes. A language change alone does not overwrite corrections. Marathi recognition is experimental: validated on three rendered Marathi words in the browser/WASM runtime, not on the user's handwriting. Noto Sans Devanagari is bundled for the transcript editor. The Devanagari PaddleOCR ONNX export and charset come from wycliffeassociates/docscanner-ocr revision 354549cf968c1d8883482a1dc74dde9c762ebf53 (Apache 2.0). See dist/vendor/recognition/devanagari/SOURCE.txt and licences.

Marathi recognition update: three horizontal renderings (original, narrower, wider) produce independent visual readings. A bundled, unmodified LibreOffice Marathi spelling dictionary (GPL-2.0, source and licence in vendor/recognition/devanagari) can promote a nearby dictionary word only when the original is unknown, the reading is sufficiently strong, and no competing dictionary word qualifies. Latin text, digits, ambiguous candidates, and already-recognized dictionary words keep their original reading. Other readings are retained for search. This improves conjunct recognition without a rule for a particular word. The revised test2 pen export reads test / Uttam / उत्तम in browser/WASM testing with the native canvas adapter. Eleven rendered Marathi samples pass; a separate प्रश्न sample still fails. This is a small regression set, not a handwriting accuracy benchmark.

Previously installed Marathi models need Language models > Resume install to add the ~1 MB spelling dictionary. Existing weights are reused. Removing Marathi clears its dictionary along with its model. Old automatic Marathi indexes refresh to version 3; saved user corrections are preserved. Recognition remains entirely on this device.

Minimal writing view: the page opens with the library hidden. Notes toggles a compact library containing All notes, Favorites, notebooks, search, and note titles. Search tools expands recognition settings, indexing, handwriting review, and language models. Library actions contains backup import/export. The main header keeps small floating groups for Type, Pen, Highlight, Eraser, Undo/Redo, and writing settings (sliders). The three-dot More menu contains Focus, a new brainstorming board, PDF import, export, handwriting review, notebook/date details, and delete. Type opens text color, size, and line spacing. Pen opens ink color and thickness. The sliders popup contains paper and input-device settings. Handwriting review opens beside the paper on larger screens and as an optional full-width panel on phones. PDF navigation and board controls appear only for those document types. Notes/Focus preferences are stored separately from note content. Ctrl/Cmd+K reveals search; Escape closes a popup or exits Focus. The layout follows the supplied examples with an open white canvas and compact floating tool groups.

Pen popup: click the Pen icon to select the pen and open Color, Thickness (Fine/Medium/Thick), and a live stroke preview below it. A second click toggles the popup closed. Tapping the paper dismisses the popup and starts drawing with the selected settings. Escape or the close button dismisses it and returns focus to the tool. Highlighter uses the same popup. The sliders popup retains paper and input-device preferences. Existing ink is unchanged by changes to pen settings.

Typed text color: click Type to open its color picker. The Type icon has a color underline and an Aa preview shows the selected color. The text color is stored independently from the pen color. New plain-text boxes, PDF text annotations, and idea-card lettering use the chosen text color. To recolor existing text, click to edit that text box or card, click Type, then choose a color; this changes the complete text box/card lettering while preserving words and spacing. Color changes support undo/redo, note backups, and reload. Changing a color with no text being edited sets the color for new text.

Type popup: Color, Text size (Small/Medium/Large), and Line spacing (Single/1.5/Double) are grouped together with a two-line preview. Click to edit an existing text box or idea card, then Type to change its formatting. New text uses the chosen defaults, saved on this device. Existing text-size values outside the presets remain selectable when reviewing imported or saved text. Formatting supports undo/redo, PDF annotations, board cards, note backup, and reload. Words and manual indentation remain plain text.
